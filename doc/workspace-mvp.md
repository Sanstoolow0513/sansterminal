# 工作区：当前实现与演进契约

产品目标是一个以终端为中心的单窗口开发工作台：多个工作区常驻，每个工作区拥有自己的终端组、文件树状态和编辑状态；点击任何终端即可进入它所属的工作区。保留现有 Windows Terminal 的终端、分屏、连接和窗口宿主。

默认文档区域已使用离线 Monaco 编辑器，替换 `RichEditBox` 与手工预览着色。文档模型、磁盘读取和保存服务独立于页面布局；保存和关闭契约见 [工作区编辑器](webview-editor-integration.md)。文件监听和新版持久化身份格式仍待实现。

## 当前体验

1. 打开开发版 `WindowsTerminalDev`。没有指定或恢复工作区时，进入独立欢迎内容页，不自动启动终端。主页与工作台是根内容区的两个互斥页面；进入主页时整个侧栏和面板容器收起，内容在标题栏下的完整区域中居中，窄窗口可滚动。后台终端和文档仍驻留。
2. 选择“新建工作区”并输入名称，或选择“打开文件夹”。文件夹选择器不可用时可用“输入文件夹路径”。文件夹工作区的首个终端从根目录启动；未选工作区时显式新建终端会进入“未命名工作区”。
3. 点击文件夹名称展开；点击文件打开编辑标签，每个文件保留到显式关闭。输入文件名或相对路径查找文件。工作区切换保留文件树节点、展开／选中状态、滚动位置和搜索词；清空搜索返回原树。搜索恢复时重新扫描匹配结果，目前没有文件监听或独立的刷新按钮。
4. 左侧工作区／终端 tabs 导航固定，拖动其右边缘调整宽度。在“设置 → 工作区布局”中选择要移动的区域、参照区域及左／右／上／下位置，预览组合后保存。文件树、终端和编辑器支持嵌套分割，例如左侧文件树、右上编辑器、右下终端；各区域及侧栏均有独立显示开关。布局和默认显示状态随设置保存。拖动工作台中的分隔线调整当前会话尺寸，不重建终端连接或编辑器模型。
5. 左侧导航常驻展示所有已打开工作区及其终端，可展开／折叠分组。点击终端直接激活所属工作区并聚焦原会话；点击工作区名称恢复该工作区，即使其中没有终端也不会自动新建。
6. 伸缩、主页、打开文件夹及新建终端共用全局 header；“＋”及配置菜单在当前工作区创建终端。`showTabsInTitlebar=true` 时 header 位于窗口标题栏，否则位于页面顶部。收起侧栏后这些操作仍可用。主页图标或默认 `Ctrl+Shift+N` 打开欢迎／最近项目页；通过最近列表或“返回当前工作区”恢复工作台。
7. 终端行关闭按钮只关闭该终端。右键工作区名称选择“关闭工作区”，有终端时确认终止其中所有会话（包括只读窗格）；取消保持原状。最近列表的“从最近列表移除”只影响最近记录，不关闭会话、不删除持久化布局或项目文件。

普通窗口的标题栏独立占据顶部空间，全局工作区 header 与窗口拖动区域位于标题栏，侧栏宽度和伸缩不移动 header。关闭 `showTabsInTitlebar` 时全局 header 位于系统标题栏下的页面顶部。终端、文件树、文档和通知均在标题栏下布局。顶部标签继续遵循 `showTabsInTitlebar` 设置；关闭该设置时使用原有系统标题栏。专注、全屏和 `showTabsFullscreen` 继续遵循现有窗口行为。

## 布局设置与快捷键

“设置 → 工作区布局”使用相对位置组合三个内容区域。选择“编辑器”“终端”“上方”并移动，可将编辑器和终端上下排列，再把文件树放到需要的位置。也可在预览中将区域拖到另一块区域的边缘，蓝色边线提示放置位置；点击预览区域可选择移动对象。两个比例滑块调整外层和内层分割比例。预览只修改设置草稿，点击设置页底部“保存”后应用；底部“放弃更改”丢弃未保存的设置修改。隐藏区域只改变显示，不关闭终端、不移除文档；窗口变窄也不会自动隐藏仍启用的区域。

“设置 → 快捷方式”中可为以下命令绑定快捷键。它们也可从命令面板执行；没有增加默认组合，避免覆盖既有绑定。含 Ctrl／Alt 的工作区快捷键在 Monaco 内通过原生宿主派发；`Ctrl+S` 仍保留给文档保存。

| 操作 | 命令 ID |
| --- | --- |
| 显示／隐藏文件树 | `Terminal.ToggleWorkspaceFiles` |
| 显示／隐藏终端 | `Terminal.ToggleWorkspaceTerminal` |
| 显示／隐藏编辑器 | `Terminal.ToggleWorkspaceEditor` |
| 显示／隐藏 tabs | `Terminal.ToggleWorkspaceTabs` |
| 打开工作区布局设置 | `Terminal.OpenWorkspaceLayout` |

例如在 `keybindings` 中添加 `{ "keys": "ctrl+alt+e", "id": "Terminal.ToggleWorkspaceFiles" }`。快捷键切换当前窗口的显示状态；设置页保存默认显示状态。即使全部区域隐藏，顶部布局入口仍可恢复区域。

`workspaceLayout` 在 `settings.json` 中保存为二叉分割树对象，叶子 `files`、`terminal`、`editor` 各出现一次。`direction: "row"` 为左右，`"column"` 为上下；`first`／`second` 可以是区域名或下一层分割，`ratio` 为第一部分占比。非法结构不会进入运行时布局。`workspaceShowFiles`、`workspaceShowTerminal`、`workspaceShowEditor`、`workspaceShowTabs` 独立保存默认显示状态。

首页与工作台保留各自的内容容器，在根内容区互斥显示；这使首页不再继承侧栏列宽，也保留后台会话。此设计沿用 [XAML 的页面容器](https://learn.microsoft.com/en-us/windows/uwp/ui-input/app-navigation)与 [WebView2 的显示／边界控制](https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2controller?view=webview2-1.0.3800.47)，不在换页时重建终端或编辑器。

## 当前能力及限制

| 操作或状态 | 当前实现 |
| --- | --- |
| 打开已驻留工作区 | 复用工作区及已有终端；无终端时保持为空，全局“＋”显式新建 |
| 切换工作区 | 复用终端连接、文件树节点和文档标签；保留编辑文本、撤销／重做和视图；恢复搜索词、选中节点、滚动位置及面板布局；已打开文档不重新读盘 |
| 关闭最后一个终端 | 留在工作区，文件树和已有预览继续可用；只有显式关闭工作区才移除其导航分组 |
| 从最近列表移除 | 只移除最近记录；不关闭驻留工作区、不删除布局和项目文件 |
| 重启 | 最近列表单独持久化；终端布局依现有恢复设置保存并重新启动进程；文档和文件树上下文不恢复 |
| 文档 | 可编辑，支持保存、未保存标记、冲突检测及保存／放弃／取消关闭确认 |

- 文档区域使用随应用打包的 Monaco 和语言 worker，提供行号、语法着色、查找、撤销／重做和 `Ctrl+S` 保存；`F6` 返回终端。支持不超过 2 MiB 的严格 UTF-8 与带 BOM 的 UTF-16 LE，保留编码、BOM 和 LF／CRLF。二进制、不支持的文本或超限文件不可编辑，没有截断回写路径。
- 文件树按需展开，每目录最多显示 500 项。底部数字是当前目录已显示的项目数，`+` 表示截断。展开路径、选中节点、滚动位置和搜索词按工作区保留在本次会话中，退出应用后不恢复。
- 搜索延迟 150 ms 后在后台执行，最多扫描 20000 项、返回 100 个匹配文件，跳过 `.git`、`node_modules`、`packages`、`bin`、`obj`、`build`。版本检查丢弃过期结果，已经开始的扫描尚不能及时取消；`packages` 可能包含 monorepo 源码，后续需改为可配置忽略规则。
- 尚无文件监听。目录展开仍在 UI 线程；文档读取、编码和保存使用后台服务。文件切换使用现有模型；保存前比较磁盘字节和文件身份，外部变化会拒绝覆盖并保留当前编辑。没有自动合并、另存为或应用退出后的草稿恢复。
- 最近记录、布局恢复与进程保活分别管理。恢复布局后启动的新 shell 不代表旧进程跨应用退出保活。

## 目标行为契约（分阶段实现）

| 用户操作 | 目标行为 | 实现阶段 |
| --- | --- | --- |
| 打开文件夹 | 创建或激活稳定 ID 的工作区；已驻留工作区不重复创建终端和文档 | 3 |
| 点击任意工作区的终端 | 定位已有终端，激活其工作区，恢复上下文，再将焦点交给该终端；不重建连接或进程 | 3～5 |
| 在终端执行 `cd` | 只改变终端当前目录，不改变终端归属或工作区根目录 | 3 |
| 关闭终端 | 只关闭该终端；关闭最后一个终端后仍可浏览和编辑工作区文件，允许显式新建终端 | 3 |
| 关闭工作区 | 独立操作；先确认将关闭其中的终端，再同步并处理未保存文档；取消时完整保留工作区 | 3～4 |
| 从最近列表移除 | 明确使用“从最近列表移除”文案；只移除最近记录，运行状态和布局清理使用各自的操作 | 3、6 |
| 点击文件或终端 | 工作区激活状态与输入焦点分别管理；`Ctrl+C/F/S` 按焦点交给相应控件 | 2、4 |
| 切换文档／工作区 | 保留缓冲区、撤销历史及视图位置；未修改的临时预览标签可复用，修改后固定，不能被下一次预览替换 | 4 |
| 保存／关闭文档 | 保存失败保留缓冲区并反馈原因；关闭未保存文档提供保存、放弃和取消；截断预览绝不能作为完整文件回写 | 4 |
| 文件被外部修改 | 无本地修改时更新内容并尽量保留位置；有本地修改时保留双方并提示冲突；保存前校验磁盘版本 | 4～5 |
| 重启恢复 | 明确恢复工作区、布局和文档的范围及版本迁移；退出前处理未保存内容；不承诺 shell 跨退出保活 | 6 |

目标身份规则：工作区 ID 不依赖名称、路径或数组下标；显示名称、根目录和终端当前目录分别保存。终端生命周期不归当前页面的显隐控制。同一实际文件优先共享文档身份与缓冲区，各工作区分别保存标签顺序、选中状态和视图位置。

当前导航仍沿用现有名称／规范化路径作为工作区 ID，未迁移持久化格式；终端归属不跟随 shell 的 `cd` 改变。独立不可变 ID 与别名迁移留待恢复格式阶段统一处理。

状态职责逐步从 `TerminalPage` 移出：`WorkspaceController` 管理归属和激活，`ExplorerService` 管理目录和搜索，`DocumentService` 与 `EditorHost` 管理文档和编辑器宿主，`ReviewService` 管理比较基准。继续复用 `Tab`、`Pane` 与现有终端连接。

## 实施顺序与验收门槛

| 阶段 | 交付内容 | 验收门槛 |
| --- | --- | --- |
| 0：行为契约 | 本文区分现状、目标和恢复语义 | 当前操作说明与代码一致；后续行为有可执行场景 |
| 1：固定标题栏 | 删除标题栏 overlay 接口、内容跨行和局部补偿间距；复用现有窗口按钮、命中测试和布局 | 应用和 UI 测试可构建；完成下述窗口验收 |
| 2：Monaco 宿主验证（已完成技术验证） | 独立 Win32 WebView2 矩形区域，离线运行 Monaco；已接入默认文档区域 | 模型、语言 worker、焦点、对话框与释放通过自动化；跨屏 DPI 与中文输入法仍需人工验收 |
| 3：常驻工作区导航 | 稳定 ID、分组终端导航、无终端工作区、独立关闭操作 | A/B/C 各两个终端均可直接选择；切换后 PID 相同；关闭最后一个终端仍留在工作区 |
| 4：可靠文档生命周期（已接入） | 文档模型与保存服务、默认 Monaco、后台读写、保存快照及关闭同步 | 未保存文本及撤销栈跨切换保留；失败不丢内容；截断文件无回写路径 |
| 5：项目浏览与审查 | 异步目录读取、树状态、监听、搜索取消和 Git 差异 | 新建文件可见，过期扫描可取消，比较基准明确 |
| 6：恢复与稳定性 | 持久化格式、迁移、恢复及资源检查 | 最近记录、布局、文档恢复可分别验证；反复切换无持续资源增长 |

阶段 2 已选择沿用原生工作台与离线 Monaco。每窗口按需创建一个编辑器宿主，维护多个文档 Model 与独立视图状态，通过来源与参数受验证的读写消息连接原生端。阶段 4 已替换原预览器，并保证正常切换、后台保存与用户关闭操作的文档生命周期。

宿主验证必须覆盖：分隔线拖动、最大化／全屏、跨 DPI、XAML 对话框层级；中文输入法与候选框、焦点切换、快捷键、右键和剪贴板；离线资源、语言 worker、开发包部署、反复切换时宿主数量和资源释放。

审查基准分别定义为：编辑缓冲区与磁盘、工作目录与 Git 暂存区、暂存区与 HEAD、任务开始时基准与当前结果。最后一项需要单独记录基准，不能把已有未提交修改都标记为某次 agent 的产出。当前布局支持文件树、终端区和单个编辑器区的嵌套组合；浮动窗口、多编辑器组、语言服务器、调试器及扩展生态另行规划。

## 当前导航验收

2026-10-03 布局验收：可组合布局纯模型覆盖 48 种结构和 1536 个几何／显隐组合；原生 TabTests 102/102、SettingsModel 164/164 通过。独立桌面副本通过 158 项实际拖放、快捷键、编辑保存及关闭检查，另有 15 项首页／重启检查。已核对完整首页、设置预览和混合布局的实际窗口截图，并部署核验最新版开发包。详细证据与运行方法见[编辑器与布局验收](webview-editor-integration.md#当前验收2026-10-03可组合布局与默认编辑器)。

- A／B／C 各两个终端全部出现在分组导航中；选择任意终端后连接对象保持不变，当前工作区和输入焦点随之切换。
- 关闭后台工作区的终端不改变当前工作区；关闭当前工作区的最后一个终端保留文件树与预览。重新点击该工作区不自动创建终端。
- 工作区关闭有会话时显示确认；取消保留状态。确认后移除工作区并切换到其他驻留工作区；最后一个工作区关闭后进入欢迎页。
